# openGrid Physical Systems Starter Library, v0.1

A small, extensible, **code-driven parametric CAD starter** for making reusable physical objects built around the openGrid 28 mm (about **1.10 inch**) grid. Designed for reusable objects and installations of any size.

**Status:** The library has four CadQuery prototypes plus native openGrid/openConnect snap and receiver generators derived from unchanged upstream author files. Automated CAD generation and validation are provided. Physical snap fit and load tests have not been performed.

The native connector generation uses pinned source geometry rather than AI approximations. See [Phase 1 interface notes](docs/PHASE1_NATIVE_INTERFACE.md).

## What's here

| File | Purpose | Output | Connection status |
|---|---|---|---|
| `cad/wall_planner.py` | Reusable 28 mm grid layout for dimensions supplied when running the planner | SVG, CSV, JSON | Exact grid pitch, no connector geometry |
| `cad/library.py` `test_pitch_coupon()` | Check 28 mm print spacing and dimensional accuracy | STEP + STL | Measurement coupon only, **not** snap-compatible |
| `cad/library.py` `grid_tray()` | Desk tray, with rear mounting tab and standardized hole-center spacing | STEP + STL | Tray functions by itself; wall attachment must be engineered using native snap |
| `cad/library.py` `vented_crate()` | One-piece storage crate, openGrid-aligned window spacing | STEP + STL | Standalone crate; windows **do not** accept openGrid snaps |
| `cad/library.py` `adapter_blank()` | Mounting plate with a pitch-aligned hole pattern | STEP + STL | Blank intended for adding verified external snap geometry |
| `config/standard.json` | Machine-readable dimensional and interface policy | JSON | Exact verified public dimensions |
| `docs/INTERFACES.md` | Genuine upstream connector integration instructions | Markdown | Source links and validation gates |
| `AGENTS.md` | Rules for AI/CAD agents building new modules | Markdown | Reuse contracts and safety gates |

All examples fit within **7.1 × 7.1 inches** in plan, so they fit both the A1 and A1 Mini build plates by nominal dimensions. Confirm actual clearances in your slicer. The tray and crate are one-piece models. Editable STEP and printable STL files are generated from the source code, or downloaded as artifacts from a successful GitHub Actions build.

## Native connector generation (Phase 1)

The new `cad/opengrid/generate_interfaces.py` exports genuine upstream openConnect snap variants for **Lite** and **Full** openGrid boards, plus a matching removable-accessory receiving plate. It uses the author's pinned OpenSCAD source stored at `vendor/mitufy-opengrid/` (CC BY 4.0, see [attribution](vendor/mitufy-opengrid/ATTRIBUTION.md)) and BOSL2.

Use a successful GitHub Actions build to download the generated 3MF connector examples, or install OpenSCAD and BOSL2 locally and run:

```bash
python cad/opengrid/generate_interfaces.py --variant all
python cad/opengrid/validate_interfaces.py
```

The 3MF connector files are **native-geometry software prototypes**, with physical fit and load testing still required.

## Quick start

Run this in a terminal (Python 3.11+ recommended):

```bash
python -m pip install -r requirements.txt
python cad/generate.py --part all
python cad/wall_planner.py --printer a1 --width "$WIDTH_IN" --height "$HEIGHT_IN"
python -m pytest -q tests
```

Open the exported `.step` files in Fusion or other STEP-aware CAD. Use Bambu Studio to load the `.stl` files and check print estimates. Edit `cad/library.py` to change dimensions or make new reusable objects.

## Wall planning without stored measurements

The library contains **no saved room measurements or default wall layouts**. The wall planner is reusable: provide measured width and height in inches each time a layout is needed. It produces SVG, CSV, and JSON files locally.

For example, supply the measurements for a specific wall before running the planner:

```bash
WIDTH_IN=your_measured_width
HEIGHT_IN=your_measured_height
python cad/wall_planner.py --printer a1 --width "$WIDTH_IN" --height "$HEIGHT_IN"
```

For the smaller printer, use `--printer a1-mini`. The generator uses full 28 mm grid cells and reports remaining border space without assuming anything about your room. Nominally safe tile defaults are **8 × 8 cells (8.82 × 8.82 inches)** on the A1 and **6 × 6 cells (6.61 × 6.61 inches)** on the A1 Mini. Verify actual exterior dimensions in the official tile generator and slicer.

No dimension-specific wall layouts are committed or generated by CI.

## Get print-ready exports from GitHub

Open [GitHub Actions](https://github.com/Danejw/opengrid-cad-library/actions/workflows/build-cad.yml) and select a successful **Build and validate parametric CAD** run. Download the `opengrid-cad-library-v0.1-exports` artifact. It includes the four CadQuery prototype STL/STEP pairs plus native openConnect connector 3MF exports. Wall plans are generated locally only from measurements you supply.

You can also run the Quick start commands locally to regenerate the exact outputs. Generated exports are not committed as binaries so changes to the source remain reproducible and the repository stays lightweight.

## Engineering preflight and visual previews (Phase 3)

The pipeline generates [a machine-readable engineering report](docs/PHASE3_PIPELINE.md) and PNG previews for every prototype. The GitHub Actions artifact includes the source-driven STL/STEP exports, preflight results and preview images.

The project deliberately does **not** claim slicer compatibility, print success, or physical connector-fit verification without evidence.

## Design principles

1. **One reusable grid:** Keep all mounting cell centers at 28 mm increments, even in crates, shelves, desk accessories, and walls.
2. **One real mating interface:** Use publisher-authored geometry for production openGrid snaps, openConnect slots, and Multiconnect. Never fake exact snap profiles.
3. **Independent structural joints:** Use properly designed joints for load-bearing crate corners, shelves, and furniture. openGrid accessory snaps are not automatically structural connectors.
4. **Parametric modules:** Store relevant dimensions as variables and generate editable CAD. Keep units clearly labeled.
5. **Version + provenance:** Document upstream interface source, printer, filament, tolerance, and results for each validated mating connector.

## Print validation checklist

- Download an official openGrid **Lite** and **Full** test panel and the matching upstream snaps, then fit them physically.
- Print `output/pitch_coupon.stl` to measure whether the printer reproduces 28 mm spacing. It is a measurement artifact, not a snap test.
- Print `output/grid_tray.stl` on the bed. It is usable standalone; do not hang it without designing and testing the actual wall connector.
- Measure real filament used in Bambu Studio. Do not infer accurate filament pounds from solid CAD volume because slicing, infill, and supports affect consumption.
- Test all loaded printed plastic parts before relying on them. Use screws into appropriate studs/anchors for wall installation.

### Why native connectors export as 3MF

STL export of the upstream source can introduce disconnected zero-area triangles and lose topology. The pipeline now preserves the author-authored closed geometry in validated **3MF** files and discards raw intermediate STL exports. These can be opened in Bambu Studio and still require real-world fit checks. The original parametric `.scad` source remains editable and pinned, and the four independent CadQuery prototypes still export both STEP and STL.

## Official publisher board assets

The Studio now includes original David D **Full** and **Lite** openGrid boards (2×2 and 4×4), from the original author's Printables files, in a separate Boards category. The checked-in 3MF files are unmodified and their SHA-256 checksums, source download IDs, and license are pinned in `vendor/davidd-opengrid/manifest.json`. Three matching original STEP files are also supplied; the Full 4×4 STEP is available at the publisher's [original listing](https://www.printables.com/model/1214361-opengrid-walldesk-mounting-framework-and-ecosystem/files). Their GLBs and previews are derived from the original mesh geometry. The pitch calibration plate is a separate nonofficial prototype. The source files have not been physically fit-tested.
